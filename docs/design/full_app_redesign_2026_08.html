우리 둘 · 전체 디자인 개편 시안

기능 정리(우리 선택 제거)와 콘텐츠 개편(서로 노트 질문 세트, 데일리 질문, 기억 카드 1000자), 그리고 노랑 계열 테마 전환에 맞춰 화면 전체의 카드 문법과 위계를 다시 맞추는 제안입니다. 세 방향을 같은 홈 화면으로 비교합니다.

1

카드 문법이 화면마다 다름

홈, 서로 노트, 기억 카드, 음악 노트가 서로 다른 radius·padding·뱃지 규칙을 씁니다. 같은 앱인데 화면을 옮길 때마다 다른 제품처럼 읽힙니다.

2

테마를 노랑 계열로 교체

기존 하늘색 한 톤은 배경·카드·뱃지가 모두 같은 계열이라 위계가 평평했습니다. 버터 크림 배경과 오커 accent로 옮겨 강조를 색이 아니라 면과 여백으로 만듭니다.

3

이번 개편이 만든 빈자리

우리 선택이 빠지면서 홈 plus grid가 한 칸 비고, 기억 카드 본문이 1000자까지 길어지면서 카드 높이 편차가 커집니다. 두 가지를 같이 정리해야 합니다.

방향 비교 · 홈 화면 390px
A · 권장

종이 카드 정리

현재 톤을 유지하되 카드 규칙(radius 22, padding 17, eyebrow 1줄)을 하나로 통일합니다. 변경 범위가 가장 작고 되돌리기 쉽습니다.

구현 노트

권장 방향은 A · 종이 카드 정리입니다. B는 위계가 또렷하지만 390px에서 스크롤이 길어지고, C는 조용하지만 탭 가능한 영역이 흐려져 이 앱의 주 사용 맥락(한 손, 짧은 시간)에 맞지 않습니다.

SCOPE

  • lib/src/shared/ui_style.dart의 색 토큰은 노랑 계열로 이미 교체됐다. 남은 일은 카드 radius·padding 상수를 한곳에서 관리하는 것이다.
  • lib/src/shared/ui_components.dart의 paper card, badge, filter pill을 단일 규칙으로 통일한다.
  • 홈 plus grid는 우리 선택이 빠진 4칸(서로 노트 · 언젠가, 같이 · 음악 노트 · 장소 보드) 기준으로 재배치한다.
  • 화면별 로컬 스타일 값은 공용 컴포넌트로 흡수하고, 남는 예외는 이유를 주석으로 남긴다.

이번 커밋에 이미 반영된 것

  • 우리 선택(taste match) 화면 · route · 저장 경로 · rules 전부 제거.
  • 데일리 질문 58개를 연애 한 달차 기준으로 교체 (id q001–q058 유지).
  • 서로 노트 슬롯을 새 id 20개로 교체 — 예전 slot id는 화면에서 더 이상 읽지 않는다.
  • 기억 카드 제목 80자 / 본문 1000자, 목록 6줄 clamp + 전체 보기 sheet.
  • 팔레트를 노랑 계열로 교체 — 배경 #FDF9EA, 표면 #FFFDF7, 주 accent #8A6B1E, 보조 #C1922C.

Firestore write 경계

  • 이 디자인 개편은 새로운 Firestore write를 만들지 않는다.
  • 카드 열람, 전체 보기 sheet, 카테고리 칩 이동, plus grid 스크롤은 write가 아니다.
  • 기억 카드 저장만 memoryCards/{cardId} 한 문서를 쓴다. 한도는 rules와 UI가 같은 값(80 / 1000)을 쓴다.
  • 서로 노트 저장은 기존대로 profileCards/{profileId}/slots/{slotId} 한 문서만 쓴다.

테스트

  • 390px에서 카드 제목·본문·뱃지가 잘리거나 겹치지 않는지 확인한다.
  • 본문 1000자 카드가 목록에서 6줄로 잘리고 전체 보기로 열리는지 widget test로 고정한다.
  • 홈 plus grid에 우리 선택 진입점이 없는지 확인한다.
  • 서로 노트 카테고리 칩(전체 · 직접 · 취향 · 하루 · 대화 · 함께)이 그대로 동작하는지 확인한다.
남은 판단. 예전 서로 노트 답변은 Firestore에 문서로 남아 있습니다. 화면에서는 보이지 않지만 실제로 지우려면 scripts/reset_profile_slots.js를 --dry-run으로 확인한 뒤 --confirm으로 실행해야 합니다. 되돌릴 수 없습니다. 우리 선택 데이터(balanceSelections)는 rules에서 경로가 사라져 더 이상 읽고 쓸 수 없습니다.
